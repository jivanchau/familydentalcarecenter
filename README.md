# Freshdent Clinic, Kohalpur: website

Clinic website, hosted on **Cloudflare Pages**. Built with React, with a royal blue theme.

| Layer | Tech |
|---|---|
| Frontend | Vite + React 19 + TypeScript + React Router 7 |
| Styling | Plain CSS with theme tokens in `src/index.css` (royal blue `#1a56a7`, green `#17882f`, Poppins) |
| Dynamic API | Cloudflare Pages Functions (`functions/api/*`) |
| Database | Cloudflare D1 (blogs + contact enquiries) |
| File storage | Cloudflare R2 (blog thumbnails, served at `/media/...`) |
| Email | Resend (optional), spam protection via honeypot + Cloudflare Turnstile (optional) |

## Project layout

```
src/
  config/site.ts        clinic name, phones, address, hours, nav menu  ← edit here
  data/content.ts       home/about content, doctors, testimonials, gallery
  data/treatments.json  15 treatment pages (generated by scripts/content/build_treatments.py)
  components/           Header, Footer, Layout, shared sections, blog.tsx (post text + thumbnails)
  pages/                Home, About, Doctor, Treatment, Gallery, Blogs, BlogPost, Contact, Legal, Admin
  lib/api.ts            blog + admin API client, contact form
functions/api/
  contact.ts            POST /api/contact  → D1 + email
  blogs/index.ts        GET  /api/blogs?page=1          (public)
  blogs/[slug].ts       GET  /api/blogs/:slug           (public)
  admin/_middleware.ts  checks the signed session cookie for every /api/admin/* route
  admin/login.ts        POST /api/admin/login · logout.ts · me.ts
  admin/blogs/*         GET/POST /api/admin/blogs · GET/PUT/DELETE /api/admin/blogs/:slug
server/shared.ts        helpers shared by functions (validation, session signing)
db/schema.sql           D1 tables
public/_redirects       permanent redirects (add old URLs here if needed)
public/_headers         security + cache headers
```

## Pages (routes)

`/`, `/about-clinic`, `/dr-bishwanat-chaudhary`, `/dr-ramesh-ram-bhandari`, `/gallery`, `/blogs`, `/blog/:slug`,
`/contact-us`, `/privacy-policy`, `/terms-and-conditions`, `/admin` (blog admin), and one route per treatment
(`/root-canal-treatment`, `/dental-implants`, `/braces-treatment`, `/clear-aligners`, …).

## Run locally

```bash
npm install
npm run db:local   # create the local D1 tables (first time)
npm run cf:dev     # full Cloudflare runtime incl. API + D1 + admin at http://localhost:8788
npm run dev        # hot-reload UI at http://localhost:5173 — /api is proxied to cf:dev on 8788
```

Local admin login lives in `.dev.vars` (git-ignored):

```
ADMIN_USERNAME=admin
ADMIN_PASSWORD=...
SESSION_SECRET=...   # 64 random hex chars: openssl rand -hex 32
```

## Deploy to Cloudflare

```bash
npx wrangler login
npx wrangler d1 create freshdent-db          # copy the database_id into wrangler.toml
npx wrangler r2 bucket create freshdent-media # storage for blog thumbnails (binding MEDIA)
npm run db:schema                             # create tables in production D1
npm run cf:deploy                             # first run creates the Pages project
# admin login (choose a strong password; you will be prompted for each value):
npx wrangler pages secret put ADMIN_USERNAME
npx wrangler pages secret put ADMIN_PASSWORD
npx wrangler pages secret put SESSION_SECRET  # paste the output of: openssl rand -hex 32
```

Then in **Cloudflare dashboard → Workers & Pages → freshdent-clinic → Settings**:

1. **Variables & Secrets**:
   - `RESEND_API_KEY` (secret) and `CONTACT_FROM` (e.g. `Freshdent Website <no-reply@your-domain.com>`). The domain must be verified in Resend.
   - Optional Turnstile: `TURNSTILE_SECRET` (secret) + build variable `VITE_TURNSTILE_SITE_KEY`.
2. **Custom domains**: add `your-domain.com` and `www.your-domain.com`.
   The domain's DNS is already on Cloudflare, so this is a one-click switch at go-live.
3. Optional: connect the Git repo so every push to `main` auto-deploys.

The contact form needs at least one of D1 or Resend configured. With neither, it returns a clear
"please call us" error instead of silently dropping enquiries.

## Managing blogs

Go to **/admin**, sign in, and use **New post**. Each post has a **title**, a **slug** (its web address,
auto-filled from the title), an optional **thumbnail** and a **description** (the article). Posts appear on
`/blogs` immediately, newest first, 9 per page; clicking a card opens `/blog/<slug>`.

- **Thumbnail:** choose or drag an image (JPG/PNG/WebP). It is resized to max 1600×1000 and converted to
  WebP in the browser before upload, then stored in R2. The server re-checks the file type from its bytes.
  Replacing or deleting a post's thumbnail removes the old file. Without a thumbnail, a branded placeholder is shown.
- **Editor:** toolbar for bold, italic, heading, subheading, bullet/numbered lists, quote and link
  (Ctrl/⌘+B, I, K), with a live preview. Posts are stored as a small, safe Markdown subset and always rendered
  as text — HTML typed into a post can never run on the site, and links only allow http(s), mailto, tel or site paths.

Existing databases created before thumbnails existed need one migration:
`npx wrangler d1 execute freshdent-db --remote --file=db/migrations/0001_blog_thumbnail.sql`

Security: the session is an HMAC-signed, HttpOnly, SameSite=Strict cookie valid for 8 hours. Changing
`SESSION_SECRET` signs everyone out. For extra protection, put `/admin*` and `/api/admin/*` behind
**Cloudflare Access** (free for small teams) so only approved email addresses can even reach the login page.

Read contact-form enquiries:

```bash
npx wrangler d1 execute freshdent-db --remote --command "SELECT * FROM enquiries ORDER BY id DESC LIMIT 20"
```
